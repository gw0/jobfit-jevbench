**Why This Role is Exciting**

We are looking for a Database Engineer with 2-3 years of experience supporting PostgreSQL databases in AWS and Azure cloud environments. The role involves database administration, monitoring, troubleshooting, backup/recovery, performance tuning, and automation support in all environments.

**Key Responsibilities**

* Support administration and maintenance of PostgreSQL databases hosted on AWS RDS and Azure PostgreSQL.
* Monitor database health, performance, replication, storage, and availability.
* Assist with database provisioning, upgrades, patching, backup/recovery, and disaster recovery activities.
* Troubleshoot database issues including slow queries, blocking, deadlocks, replication lag, and connectivity problems.
* Support SQL performance tuning and collaborate with application teams on optimization efforts.
* Manage database security, users, roles, and access controls.
* Assist in automating routine DBA tasks using Bash or Python scripting.
* Work with monitoring and observability tools such as Grafana, CloudWatch, Azure Monitor, Prometheus.
* Maintain operational documentation, runbooks, and standard procedures.

**Attributes of a Successful Candidate**

* Bachelor’s degree in computer science, Information Technology, or related field.
* 2–3 years of hands-on PostgreSQL administration experience.
* Experience supporting PostgreSQL in AWS and/or Azure cloud environments.
* Good understanding of PostgreSQL architecture, backup/recovery, replication, and performance tuning concepts.
* Experience in working with applications hosted in Kubernetes infrastructure.
* Strong SQL troubleshooting and analytical skills.
* Familiarity with monitoring, alerting, and incident management processes.
* Good communication and collaboration skills.

**Preferred Skills**

* Experience with:

  + AWS RDS PostgreSQL and Azure PostgreSQL Flexible Server
  + PgBouncer or connection pooling solutions
  + Terraform or Infrastructure as Code tools
  + CI/CD and DevOps practices
  + Kubernetes-based environments
* Knowledge of logical replication, CDC tools, and high availability architectures.
* Relevant PostgreSQL or cloud certifications are a plus.
