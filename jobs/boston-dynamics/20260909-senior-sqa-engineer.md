**Summary**
-----------

As an SQA Engineer on the Spot team, your role will be central to ensuring the high quality, reliability, and performance of our integrated robotics ecosystem. You will bridge the gap between web application testing and embedded robotic systems by validating both our Orbit fleet management web platform and the physical autonomous robots. In this role, you will apply holistic systems thinking—analyzing and testing the full end-to-end system (robot hardware, embedded software, and web infrastructure) rather than isolated components. You will focus heavily on test development, building robust automated test suites, developing Hardware-in-the-Loop (HIL) testing strategies, and establishing automated testing best practices across the entire platform.

**Primary Responsibilities**
----------------------------

* Design, develop, and maintain automated test frameworks for both web applications (Orbit) and embedded robotic systems.
* Apply systems thinking to design test architecture and automated test cases that validate full end-to-end user workflows, from the Orbit web interface down to robot actuation, navigation, and payload operations.
* Implement Hardware-in-the-Loop (HIL) automated testing to rigorously validate robot performance, dynamic stability, environmental perception, and autonomy.
* Develop comprehensive test plans and test development strategies to ensure thorough verification across browsers, web APIs, and robotic hardware variants.
* Collaborate closely with web developers, embedded software engineers, and hardware teams to understand system architecture and identify testability requirements.
* Perform complex troubleshooting and root-cause analysis across software and physical hardware boundaries, analyzing system logs, web traffic, and telemetry.
* Integrate automated web and system test suites into continuous integration/continuous deployment (CI/CD) pipelines to drive early feedback and continuous quality.

**Qualifications & Requirements**
---------------------------------

* Bachelor’s degree in Electrical Engineering, Computer Engineering, Computer Science, Robotics, or a related technical field.
* 3+ years of experience in automated software testing for web applications and complex electromechanical/robotics systems.
* Proven expertise in web automation, ideally using Playwright.
* Strong proficiency in Python for system test development and test framework integration (e.g., pytest). Familiarity with C++ and/or Typscript/Javascript is highly desirable.
* Hands-on experience with Hardware-in-the-Loop (HIL) automation and testing physical robotics or embedded platforms.
* Demonstrated systems-thinking approach to software quality, with the capability to analyze end-to-end interactions across web applications, REST APIs, network connectivity, and robotic control systems.
* Experience with version control, build systems, and CI/CD toolchains (Git/GitHub, BuildKite, Jenkins, or similar).
* Strong problem-solving skills with a ‘tinkerer/builder’ mindset and enthusiasm for hands-on work with robotic hardware.

**Desirable Experience**
------------------------

* Experience testing web interfaces for controlling embedded or autonomous hardware systems.
* Understanding of modern web frameworks (React.js), HTML, CSS, and RESTful APIs.
* Experience with Jira, TestRail, or equivalent test management platforms.
* Familiarity with Agile/Scrum methodologies in continuous delivery environments.
* Direct experience in planning and executing test strategies for complex robotic or autonomous systems, including simulation, field testing, or hardware stress testing.
