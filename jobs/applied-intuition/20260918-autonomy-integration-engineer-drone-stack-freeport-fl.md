**About the Role**
------------------

As an Autonomy Integration Engineer within our Drone Stack team at Applied Intuition, you will serve as the technical anchor bridging hardware, edge software, and field flight operations. Split roughly 50/50 between the lab and the airfield, you will be responsible for bringing autonomous aerial systems from initial benchtop configuration to live operational flight.

In this role, you will configure embedded Linux environments, deploy and validate containerized software stacks, wire up mesh network topologies, and write key middleware glue code to keep subsystems communicating seamlessly. You are as comfortable with a soldering iron and oscilloscope at the bench as you are SSH-ing into an onboard computer over a mesh radio under field conditions.  
  
This opportunity can also be located at our HQ in Sunnyvale, CA or Ann Arbor, MI office (relocation offered).

**What You'll Do**
------------------

* Lead System Bring-Up: Drive end-to-end hardware and software integration for unmanned aerial systems, moving platforms from benchtop prototyping to active flight test campaigns.
* Deploy & Configure Edge Software: Manage, configure, and deploy software stacks using Docker images, shell scripts, and Linux system tools across onboard computes and peripheral hardware.
* Field & Bench Troubleshooting: Troubleshoot vehicle networks, payload interfaces, and sensor links in real time using command-line tools (grep, less, journalctl, nano/vim) and hardware diagnostics (multimeters, oscilloscopes).
* Build Test Tooling & Glue Code: Develop Python and C++ scripts for data reduction, log analysis, system validation, and real-time subsystem verification.
* System Cabling & Electronics: Fabricate custom wiring harnesses, perform precision soldering, and define system-level architecture using clear block diagrams.
* Manage Communications & Networks: Configure IP routing, subnets, and local network interfaces between flight controllers, companion computers, radios, and ground control stations.

What We're Looking For
----------------------

* Experience: 5+ years of experience in robotics integration, flight test engineering, embedded systems, or autonomous vehicles (aerial background preferred).
* Linux & Networking Mastery: Deep practical comfort with the Linux CLI, file management, system logging, local IP routing, subnets, and containerized deployments (Docker).
* Hardware & Electronics Capability: Proven hands-on skills in wiring, custom cable assembly, bench soldering, and physical diagnostics using oscilloscopes and multimeters.
* Scripting & Glue Code: Strong proficiency in Python, C++, or Shell scripting for automation, test suite creation, and processing flight data logs.
* Protocols: Direct experience working with serial and vehicle bus protocols (UART, CAN, Ethernet, SPI, I2C).
* Leadership: Ability to lead major integration efforts independently and act as the technical link between software, GNC, and hardware teams.
